## 계약 입장 <a href="#id-1-1" id="id-1-1"></a>

* 생성된 링크 또는 QR을 통해 아래와 같은 입장 화면으로 입장합니다. 서명자는 이메일 또는 휴대폰 번호 중 하나를 입장 수단으로 선택할 수 있습니다.

> [!info]
> 링크 계약 생성 시 휴대폰 인증을 선택한 경우 휴대폰 번호로만 계약 입장 가능합니다.

![[img-3093ee22ce9a.png]]![[img-5a9c42f4624c.png]]

1. **이메일:** 이름과 이메일을 입력 후 계약에 입장합니다. 입장하여 생성된 계약은 입력한 이메일로 발송 됩니다.
2. **휴대폰 번호:** 이름과 휴대폰 번호를 입력 후 계약에 입장합니다. 입장하여 생성된 계약은 입력한 번호의 카카오톡으로 발송됩니다. 만일 카카오톡에 가입되어있지 않은 번호일 경우 SMS로 발송됩니다.

* 필요 정보 입력 후 **[계약 입장]** 버튼을 클릭하면 아래와 같이 계약 현황 화면으로 이동합니다. 계약 현황 화면에서 **[이동하기]** 버튼을 클릭해 계약서를 열람할 수 있습니다.

![[img-e78da8439c48.png]]

## 입력 시작 <a href="#undefined" id="undefined"></a>

* 계약서를 확인 후 계속 진행을 원하시면 좌측 **[입력 시작]** 버튼을 클릭합니다.

![[img-8dc9e5a78572.png]]

> [!note] 계약 거절 방법
> 계약서에 이상이 있거나, 더 이상 계약을 진행하고 싶지 않은 경우, 계약을 거절할 수 있습니다.

## 입력 완료 <a href="#undefined-1" id="undefined-1"></a>

* 필수 내용 및 서명/도장을 입력을 완료하신 경우 마지막 입력 칸의 완료 버튼 또는 좌측에 입력 완료 버튼을 클릭합니다

![[img-7048d2ebc44d.png]]

* 입력 완료 버튼 클릭 시 **입력 완료 전 최종 확인 사항** 안내가 생성됩니다. 해당 안내를 꼼꼼히 확인 후 동의 및 **[확인]** 버튼을 클릭해주세요.

![[img-d8585b865e5c.png]]

> [!danger]
> **확인 버튼 클릭 후에는 수정 및 추가 입력이 불가능 합니다.**
