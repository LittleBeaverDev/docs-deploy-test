수신 받은 계약 열람, 정보 및 서명 입력 방법을 알아보겠습니다

> [!info]
> 계약 서명자는 도뉴에 회원 가입 하지 않아도 수신 된 계약서를 열람할 수 있습니다.

### 1. 계약 수신

이메일 또는 카카오톡으로 수신한 계약 알림 하단에 있는 **[서명하기]** 버튼을 클릭합니다.

![[img-62f3e8b86735.png]]

### 2. 계약 입장

수신인 이름을 입력 후 **[확인]** 버튼을 클릭합니다.

![[img-7aafcb040310.png]]

> [!danger]
> 계약 입장이 안돼요!
>
> ~님 전에 있는 단어를 정확히 입력해야 수신인 인증이 가능합니다.
>
> 만일 계약을 보낸 상대방이 예시와 같이 공백을 추가했을 경우, **공백도 동일하게 입력**해야 입장이 가능하니 확인 후 정확히 입력해주세요.
>
> 예시)
> * 김도뉴님 → '김도뉴' 입력
> * 김도뉴 님 → '김도뉴 ' 입력

### 3. 계약 열람

계약 현황 화면에서 받으신 계약 화면으로 **[이동하기]** 버튼을 클릭해 이동합니다.

![[img-55dbb856683b.png]]

### 4. 입력 시작

계약서를 확인한 후 계속 진행을 원하시면 좌측 **[계약 입력 시작]** 버튼을 클릭합니다.

![[img-8dc9e5a78572.png]]

> [!note] 계약 거절 방법
> 계약서에 이상이 있거나, 더 이상 계약을 진행하고 싶지 않은 경우, 계약을 거절할 수 있습니다.
>
> 계약 거절 방법에 대해 더 자세히 알고 싶은 경우 아래 링크를 확인하시기 바랍니다.
>
> > [!tip] 관련 문서
> > [[계약서 열람 및 서명/수신자 서명 방법/계약 서명 전 거절 방법|계약 서명 전 거절 방법]]

### 5. 입력 완료

1. 필수 정보 및 정보 입력을 완료하신 경우 마지막 입력 칸의 완료 버튼 또는 좌측에 입력 완료 버튼을 클릭합니다.

> [!note] 계약 입력 방법
> 계약 입력 방법에 대해 더 자세히 알고 싶은 경우 아래 링크를 확인하시기 바랍니다.
>
> > [!tip] 관련 문서
> > [[계약서 열람 및 서명/생성자 서명 방법/계약서 요청 정보 입력 방법|계약서 요청 정보 입력 방법]]

![[img-7048d2ebc44d.png]]

2. 입력 완료 버튼 클릭 시 [입력 완료 전 최종 확인 사항] 안내가 생성됩니다. 해당 안내를 꼼꼼히 확인 후 동의 및 확인 버튼을 클릭해주세요.

![[img-d8585b865e5c.png]]

> [!danger]
> 확인 버튼 클릭 후에는 수정 및 추가 입력이 불가능 합니다.
