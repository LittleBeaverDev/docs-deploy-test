계약서에 본인이 입력해야 하는 정보가 있을 때 입력 단계에서는 해당 정보를 입력할 수 있습니다. 모든 서명자가 정보를 입력하고 서명해야 계약이 체결됩니다.

* 먼저, 상세 계약 화면을 통해 계약 정보를 확인합니다.

![[img-2f3e8fc26616.png]]

* 계약 정보에 이상이 있는지 확인 후 이상이 있는 경우 계약을 거절할 수 있습니다.

> [!note] 계약서 입력 전 거절 방법
> 거절에 대해 더 자세히 알고 싶은 경우 아래 링크를 확인하시기 바랍니다.
>
> > [!tip] 관련 문서
> > [[계약서 열람 및 서명/생성자 서명 방법/계약서 서명 전 파기 방법|계약서 서명 전 파기 방법]]

* 이상이 없는 경우, 좌측의 **[계약 입력 시작]** 을 눌러 입력을 시작합니다.

![[img-8dc9e5a78572.png]]

* 입력을 시작하게 되면 첫 번째 작업부터 진행하게 됩니다.
* 항목에 따라 반드시 입력해야 하는 필수 항목과 입력하지 않아도 되는 선택 항목으로 나뉘게 됩니다.

## 텍스트 입력

* 계약 생성자가 요구한 정보를 입력합니다.

![[img-67639789ecde.png]]

## 체크박스 선택

* 원하는 옵션을 확인 후 체크박스를 선택합니다.

![[img-d7aa9a0c0773.png]]

## 손글씨 입력

* 손글씨 영역을 선택하면 손글씨 입력 모달이 제공됩니다.
* PC에서는 마우스, 모바일에서는 손가락으로 손글씨를 입력한 후 **[입력하기]** 버튼을 눌러야 입력이 완료됩니다.

![[img-716e592ac976.png]]

## 옵션 선택

* 옵션 선택 영역을 선택하면 생성자가 설정한 옵션들이 제공됩니다. 이 중 자신에게 맞는 옵션을 선택합니다.

![[img-5c2f239873c6.png]]

## 이미지 업로드

* 이미지 영역을 선택하면 이미지 업로드 모달이 제공됩니다. 한 개의 이미지 파일을 업로드한 다음 **[입력하기]** 버튼을 선택해야만 이미지 업로드가 완료됩니다.

![[img-7d31d4dc7c8c.png]]

* 모든 작업 항목을 완료하면 좌측의 **[계약 입력 완료]** 버튼이 활성화되며, 해당 버튼을 선택하면 입력 완료 전 최종 확인 사항 팝업창이 제공됩니다.

![[img-7048d2ebc44d.png]]

* 계약 체결과 관련된 사항을 확인할 수 있으며, 입력 완료 후 입력된 정보는 수정이 불가능하기 때문에 정보를 정확히 입력했는지 확인할 수 있습니다.
* 모든 내용 확인 후 체크박스를 선택하면 **[동의 시 완료 가능]** 버튼이 **[입력 완료]** 버튼으로 활성화되며, **[입력 완료]** 버튼을 선택하면 서명 입력이 완료됩니다.

![[img-d8585b865e5c.png]]

* 이후 모든 서명자가 입력을 완료하면 자동으로 계약이 체결됩니다.
