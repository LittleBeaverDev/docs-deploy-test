요금제 해지 및 환불 방법을 알아보겠습니다.

## 요금제 해지와 환불

> [!warning]
> **요금제 환불**
>
> * 요금제 구매 후 7일 이내 한 건도 사용하지 않았을 경우
>
> **요금제 해지**
>
> * 요금제 구매 후 7일이 경과했거나, 한 건이라도 사용했을 경우 환불은 불가능 하며 잔여 건수는 해지 후 남은 기간 동안 사용 가능

1. 로그인 후 왼쪽 메뉴 탭에서 **[계약 건수]** 를 클릭하여 요금제 페이지로 이동합니다.

![[img-4ef9167c2fee.png]]

2. 요금제 관리 페이지 > 사용중인 요금제 우측에 있는 **[요금제 정보]** 버튼을 클릭합니다.

![[img-fc5de588a6fa.png]]

3. 요금제 정보 창 하단에 위치한 **[요금제 환불/요금제 해지]** 버튼을 클릭 후,  **[환불하기/해지하기]** 버튼을 클릭합니다.

![[img-cc83a10b29f0.png]]

![[img-87c009c329b6.png]]

4. 환불 전 확인 사항 동의 후 **[환불하기/해지하기]** 버튼을 클릭하면 환불/해지 처리가 완료 됩니다

![[img-0d68f7a7735c.png]]
