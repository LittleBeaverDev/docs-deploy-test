요금제 구매 방법을 알아보겠습니다.

## 1. 요금제 구매 <a href="#undefined" id="undefined"></a>

1. 로그인 후 왼쪽 메뉴 탭에서 **[계약 건수]** 를 클릭하여 요금제 관리 페이지로 이동합니다.

![[img-87ef67c04f53.png]]

2. 요금제 관리 페이지 우측에 **[요금제 구매]** 버튼을 클릭합니다.

![[img-30c8a3ba0af4.png]]

3. 요금제 구매 화면에서 구매를 원하는 요금제 하단 **[구매하기]** 버튼을 클릭합니다.

![[img-e902b38e2e43.png]]

4. 구매하기 버튼을 누를 시 해당 요금제의 정보 확인이 가능합니다.\
   결제할 카드 추가 및 하단 확인 사항 동의 후  **[구매하기]** 버튼을 클릭합니다.

![[img-4d0232980ce5.png]]

5. 요금제 구매가 완료되면 아래와 같은 페이지가 생성되며 왼쪽 메뉴 탭에서 사용 가능한 **계약 건수** 를 확인할 수 있습니다.

![[img-7393f70f2333.png]]

> [!info]
> 도뉴에는 두  가지 회원 유형이 있으며, 유형 별 구매 가능한 요금제는 아래와 같습니다.
>
> * 개인 회원: BASIC 요금제 구매 가능
> * 기업 회원: PRO 50, 100, 300 & Enterprise, 맞춤형 요금제 구매 가능
> * 맞춤형 요금제는 [고객센터](https://donue.channel.io/lounge)를 통해 문의 주시기 바랍니다.
>
> 각 요금제 별 자세한 내용은 [요금 안내](https://donue.co.kr/pricing/) 페이지에서 확인 할 수 있습니다.
