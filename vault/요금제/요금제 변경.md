요금제 변경 방법을 알아보겠습니다.

## 요금제 변경

> [!info]
> 요금제 변경 시 유의 사항
>
> * 변경 된 요금제는 현재 사용중인 요금제가 종료된 후 적용 됩니다.

1. 요금제 관리 페이지 우측에 있는 **[요금제 변경]** 버튼을 클릭합니다.

![[img-66ae1e022a70.png]]

2. 요금제 변경 페이지에서 변경을 원하는 요금제 하단에 위치한 **[구매하기]** 버튼을 클릭합니다.

![[img-1a893490ed28.png]]

3. 변경을 원하는 요금제의 내용과 약관 확인 후 **[변경하기]** 버튼을 클릭합니다.

![[img-48dde12e2a2a.png]]

4. 요금제 변경하기가 완료되면 아래와 같은 페이지가 생성되며 왼쪽 메뉴 탭에서 사용 가능한 **계약 건수** 를 확인할 수 있습니다.

![[img-3cc544dc1b58.png]]
