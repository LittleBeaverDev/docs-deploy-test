자주 계약을 체결하는 상대방의 정보를 저장하여, 계약 생성 시 연락처를 쉽고 빠르게 불러올 수 있는 주소록 기능에 대해 알아보겠습니다.

도뉴는 주소록 등록 방식에 따라 **[개별 등록]** 과 **[일괄 등록]** 으로 분류합니다.

* **개별 등록:** 한 명씩 정보를 직접 입력하여 주소록에 추가합니다.
* **일괄 등록**: 제공되는 엑셀 양식을 이용하여 다수의 인원을 주소록에 일괄 등록합니다.

## 1. 연락처 추가

![[img-f05f7870cbe9.jpg]]

* 좌측 메뉴 탭에서 **[주소록]** 버튼을 클릭하여 주소록 화면으로 이동합니다.
* 상단의 **[추가하기]** 버튼을 클릭하면 추가 방식을 선택하는 팝업이 나타납니다.

### **개별 등록**

한 명씩 정보를 직접 입력하여 주소록에 추가하는 방식입니다.

1. 추가 방식 선택 팝업에서 **[개별 등록]** 을 클릭합니다.

![[img-36a1cf0ba3cd.jpg]]

2. 주소록 추가 화면에서 **기본 정보**인 이름과 이메일을 입력합니다. 필요에 따라 **추가 정보(선택)** 항목인 휴대폰 번호, 연락처, 기업명, 직급을 입력합니다.

![[img-25b1853c15ac.jpg]]

> [!info]
> **이름과 이메일은 필수** 입력 항목입니다. 추가 정보는 선택 사항으로, 입력하지 않아도 등록이 가능합니다.

3. **[완료]** 버튼을 클릭하면 주소록에 연락처가 추가됩니다.

![[img-1d1bb09e969f.jpg]]

### **일괄 등록**

엑셀 양식을 이용해 다수의 인원을 한 번에 주소록에 등록하는 방식입니다.

1. 추가 방식 선택 팝업에서 **[일괄 등록]** 을 클릭합니다.

![[img-d6d737e29f22.jpg]]

2. 일괄 등록 팝업의 **Step 1**에서 다운로드 아이콘을 클릭하여 **[도뉴]주소록\_양식.xlsx** 파일을 다운로드 받습니다.

![[img-134f6d43468e.jpg]]

3. 양식을 열어 정보를 입력합니다.
   * **필수 입력 정보** : 주소록에 등록할 이름 및 이메일을 입력합니다.
   * **선택 입력 정보** : 국가코드, 휴대폰 번호, 연락처, 기업명, 직급을 선택적으로 입력할 수 있습니다.
   * 엑셀 13행부터 작성하시길 바랍니다.

![[img-0c2b87a54271.jpg]]

4. 작성이 완료된 파일을 **Step 2**의 업로드 영역에 끌어오거나, 클릭하여 업로드합니다. **[업로드하기]** 버튼을 클릭하면 양식에 입력된 연락처가 주소록에 일괄 등록됩니다.

![[img-1a346b0cfa2a.jpg]]

## 2. 연락처 수정 및 삭제

### **수정**

* 주소록 목록에서 수정하려는 연락처에 마우스를 올리거나 선택하면 우측에 편집 아이콘이 나타납니다.
* 편집아이콘을 클릭하여 정보를 수정할 수 있습니다.

![[img-c84104294e6a.jpg]]

### **삭제**

* 삭제하려는 연락처의 체크박스를 선택하면 상단의 **[삭제하기]** 버튼이 활성화됩니다. **[삭제하기]** 버튼을 클릭하여 선택한 연락처를 삭제할 수 있습니다.
* 또한, 삭제하려는 연락처에 마우스를 올리면 우측에 삭제 아이콘이 나타납니다. 해당 아이콘을 클릭하면 연락처를 삭제할 수 있습니다.

![[img-e991af069d6c.jpg]]

> [!info]
> 상단 체크박스를 선택하면 전체 연락처를 한 번에 선택할 수 있습니다.

## 3. 연락처 추출

주소록에 저장된 연락처를 엑셀 파일로 내보낼 수 있습니다. 추출하려는 연락처의 체크박스를 선택한 후 상단의 **[추출하기]** 버튼을 클릭합니다.

![[img-7b65ba35b0e8.jpg]]
