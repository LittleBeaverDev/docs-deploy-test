도뉴에서 체결한 계약을 검증할 때 제공되는 정보들은 각각 무엇을 의미하는지 알아보겠습니다.

## FIRMACHAIN을 통한 계약 검증

도뉴는 다음 2가지 방법으로 체결한 계약 보안을 강화합니다.

1. AWS : 계약서를 암호화 후 저장 및 백업
2. 블록체인 : 체결한 계약서를 해시 함수로 추출한 \*해시값을 피르마체인에 등록

> [!info]
> 해시값이란?
>
> 계약서에 암호화된 함수를 적용시키면 숫자와 알파벳으로 이루어진 하나의 값이 추출되는데 이 값을 해시값이라합니다.
>
> 해시값은 해당 계약서만 가지고 있는 고유값으로, 계약서에 이상이 없으면 매번 동일한 값이 추출되지만, 계약서에 이상이 생겨 원본과 달라지면 변한 값이 추출됩니다.

도뉴에서 진행한 계약 검증은 2번 블록체인을 활용한 방식으로, FIRMACHAIN의 계약 검증을 간단하게 사용해 볼 수 있도록 개발된 기능입니다.

 FIRMACHAIN에서 진행하는 계약 검증은 다음 링크에서 해볼 수 있습니다.

* 링크 : <https://verify.firmachain.io/>

링크에 입장하면 계약 검증 화면이 제공되며, [VERIFICATION] 버튼을 누른 후 도뉴에서 체결한 계약서를 업로드합니다.

![[img-6cfbec246069.png]]

계약서를 업로드하면 계약 검증이 진행되며, 검증이 완료되어 계약서에 이상이 없으면 다음과 같은 정보들이 제공됩니다.

![[img-3f7e5f0cdf39.png]]

1. CREATOR : FILE HASH 값을 피르마체인에 등록한 주체의 지갑 주소로 저희 도뉴를 의미합니다. FILE HASH 값을 피르마체인에 등록할 때 수수료값이 발생하며, 수수료값은 저희 도뉴에서 지불합니다.
2. TX HASH : FILE HASH 값을 피르체인에 등록할 때 생기는 값입니다. Transaction Hash의 약자로, 클릭 시 실제로 FIRMACHAIN에 기록된 상세 계약 정보들을 확인할 수 있습니다.
3. FILE HASH : 도뉴에서 체결한 계약서에 부여되는 고유값으로 FIRMACHAIN에 기록되는 값입니다. 계약서 파일 변환 또는 위변조가 발생기면 고유값이 달라지는데, 이를 이용해 계약서에 이상이 발생했는지 확인 할 수  있습니다.
4. METE DATA : 도뉴에서 체결한 계약과 관련된 간단 정보들 암호화해서 보여집니다.
5. OWNER LIST : 해당 계약에 참여한 생성자, 서명자, 참조자의 정보입니다. 모두 암호화해서 보여지기 때문에 해당 인물이 어떤 인물인지 알 수 없습니다.
6. TIME STAMP : 계약이 체결된 원본 파일이 생성된 시간입니다.

## 상세 계약 정보 화면

TX HASH를 클릭하면 해당 계약의 상세 정보가 등록된 FIRMACHAIN 화면으로 이동합니다.

하단으로 이동하면 Messages 탭이 제공되는데 해당 탭에 등록된 정보들은 모두 계약을 진행하면서 발생한 정보를 기록들입니다.

![[img-441ed3ed8358.png]]

1. Add Contract Log : 계약을 진행하면서 발생한 로그 정보입니다. 계약 생성, 서명자 추가, 계약서 전송, 서명 등 다양한 로그들을 확인할 수 있습니다.
2. Create Contract File : 도뉴에서 계약이 완료되면 감사추적인증서가 발급되며, 감사추적인증서의 정보들 암호화해서 보여집니다.

> * 계약서에 위변조가 발생했을 경우
