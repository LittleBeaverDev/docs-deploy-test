편리한 계약 체결을 위한 도뉴의 서명 관리 기능을 지금부터 알아보겠습니다.

전자 서명이나 도장을 보유하고 있지 않은 사용자는 도뉴가 제공하는 캘리그래피 및 도장 이미지 서비스를 활용하여 서명 및 도장을 제작할 수 있습니다.

## 서명/도장 생성

* 서비스 좌측 메뉴 탭에서 **[서명/도장 관리]** 를 클릭하여, 서명/도장 관리 화면으로 이동합니다.

![[img-04b3b124a7fb.png]]

* 좌측 상단에 위치한 **[서명/도장 생성]** 을 클릭 후, **[서명]** 또는 **[도장]** 중 원하는 서명 방식을 선택해주세요.

![[img-371085583611.png]]

### 1. 서명 생성

* **[서명 생성]** 을 클릭하면 서명하기, 서명 만들기, 서명 업로드 이 세 가지 방법을 사용하여 계약서에 사용되는 서명을 만들고 저장할 수 있습니다.

![[img-edeaa393d271.png]]

*서명하기*

![[img-8f53ead15f96.png]]

*서명 만들기*

![[img-760138218e49.png]]

*서명 업로드*

> [!note] 서명하기
> * 서명하기에서는 화면에 제공되는 트랙 패드에 마우스를 드래그하여 직접 나의 서명을 그릴 수 있습니다. (태블릿을 사용하면 스마트펜 등을 활용하여 서명을 그릴 수 있습니다.)

> [!note] 서명 만들기
> * 서명 만들기를 선택할 경우, 사용자가 제작하고 싶은 서명의 텍스트를 입력창에 입력합니다.
> * 입력 후 **[만들기]** 를 클릭하면 도뉴의 캘리그래피 서비스를 통해 사용자의 서명을 아래와 같이 제작해 드립니다.
> * 캘리그래피 이미지 중 서명으로 사용할 이미지를 선택한 후, **[생성하기]** 를 클릭해 서명을 저장합니다.

> [!note] 서명 업로드
> * 서명 업로드를 선택하면, 기존에 보유하고 있는 서명 이미지를 업로드할 수 있습니다.

### 2. 도장 생성

* **[도장 생성]** 을 클릭하면 도장 만들기, 도장 업로드 두 가지 방법을 사용하여 계약서에 사용되는 도장을 만들고 저장할 수 있습니다.

![[img-6dfa0939f5ce.png]]

*도장 만들기*

![[img-650eaf4bae20.png]]

*도장 업로드*

> [!note] 도장 만들기
> * 도장 만들기를 선택할 경우, 사용자가 제작하고 싶은 도장에 들어갈 텍스트를 입력창에 입력합니다.
> * 입력 후 **[생성하기]** 를 클릭하면 도뉴가 보유하고 있는 도장 이미지에 사용자가 입력한 텍스트를 넣어 도장을 아래와 같이 제작해 드립니다.
> * 위의 도장 이미지 중 사용할 도장을 선택한 후 **[생성하기]** 를 클릭해 도장을 저장합니다.

> [!note] 도장 업로드
> * 도장 업로드를 선택하면, 기존에 보유하고 있는 도장 이미지를 업로드할 수 있습니다.

### 3. 기본 서명/도장 설정

* 기본 서명/도장 설정 시 해당 서명/도장이 우선적으로 입력됩니다.
* 서명과 도장 각 하나씩만 기본으로 설정 할 수 있습니다.
* **설정 방법**
  1. 서명/도장 생성 시 하단 기본 서명 설정 체크 박스 선택 후 **[생성하기]** 버튼 클릭
  2. 서명/도장 관리에서 기본 서명 또는 기본 도장으로 설정할 이미지 우측 상단의 **핀** 모양을 선택
  3. 기본으로 설정하고 싶은 서명/도장 선택 후 우측 **[기본 서명/도장 설정]** 버튼 클릭

### 4. 폴더 생성

* 우측 상단의 **[폴더 생성]** 을 클릭합니다.
* 팝업창에서 서명/도장을 저장할 폴더의 이름 및 폴더에 대한 설명을 필요 시 입력한 후 **[확인]** 을 클릭하여 폴더를 생성합니다.

![[img-7a8e26e8f9e0.png]]

*폴더 생성 버튼*

* 폴더로 이동하고자 하는 서명/도장을 선택한 후 우측 상단 **[옮기기]** 를 클릭하여 자유롭게 이동할 수 있습니다.
