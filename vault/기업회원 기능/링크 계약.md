URL 또는 QR 코드를 공유하여 손쉽게 계약을 진행할 수 있는 링크 계약 생성부터 관리하는 방법을 알아보겠습니다.

## 링크 계약 생성 <a href="#id-1" id="id-1"></a>

![[img-da1c20c574f3.png]]

* 도뉴에 로그인 후 왼쪽 메뉴 탭에서 **[계약 작성]** 을 클릭 후 계약 유형에서 **[링크 계약]** 을 클릭합니다.

![[img-38dd5bd94cec.png]]

*링크 계약 생성 화면*

1. **계약명:** 진행할 계약 이름을 입력합니다.
2. **생성자:** \
   **-** 정보: 생성자 본인의 정보 확인이 가능하며, 번호 노출 여부를 선택할 수 있습니다. \
   **-** 서명 여부: 서명 안함 또는 서명 하기 중 하나를 선택할 수 있습니다.\
   **-** 계약 알림: 설정 시 계약이 체결,  취소 또는 파기 되었을 때 이메일로 알림을 받을 수 있습니다.
3. **서명자:** \
   \- 서명자 인증: 서명자의 인증 여부를 선택할 수 있습니다. 휴대폰 인증( PASS 인증) 선택 시 계약 상대방은 휴대폰 번호 인증을 진행해야 입장이 가능합니다.\
   \- 중복 참여: 동일한 이메일/휴대폰으로 두건 이상의 계약 생성을 허용 또는 제한 합니다.
4. **계약 설정:** \
   **- 계약 체결 수 제한:** 링크 계약은 계약 체결 시 계약 건수가 차감 됩니다. 계약 건수를 설정하면 예기치 않은 소비를 방지할 수 있습니다.\
   **- 기한 설정:** 설정 한 기한 이후에는 링크가 자동으로 비활성화 됩니다. 생성 후 언제든지 수동으로 기한 변경 및 활성화 시킬 수 있습니다.\
   \- **입장 화면 문구:** 링크에 입장하는 상대방에게 보여지는 문구를 설정할 수 있습니다.
5. **계약 업로드:** 업로드할 파일을 직접 끌어 오거나, 내 컴퓨터, DropBox 및 Google Drive에 저장된 파일을 업로드 할 수 있습니다.

​

### 계약 편집 <a href="#id-2" id="id-2"></a>

* 도뉴에서는 보안상의 이유로 생성자만 계약서 편집이 가능합니다. \
  [편집 도구]와 [서명자 도구] 두 가지 도구를 활용하여 계약서를 편집할 수 있습니다. \
  자세한 방법은 [[계약 생성/계약서 편집 및 전송| 계약서 편집]] 에서 확인할 수 있습니다.

![[img-65f6d1b9373b.png]]

### 검토 <a href="#id-3" id="id-3"></a>

* 편집을 완료 후 다음 버튼을 클릭하여 검토 단계로 넘어갑니다.

![[img-1a2b28c53993.png]]

*계약 검토 화면*

* 검토 단계에서 아래의 정보를 확인할 수 있습니다.
  * 생성자: 생성자 정보, 생성자 계약 서명 여부, 계약 알림 설정 여부
  * 서명자: 서명자 인증(PASS 인증), 중복 참여 허용 여부
  * 계약 설정: 계약 체결 수, 체결 가능 기한 및 입장 화면 문구

* **첨부 파일**
  * 첨부 파일을 추가하고 목록을 확인할 수 있습니다.
  * 첨부 파일은 최대 2GB 까지 업로드 가능합니다.
  * exe, dll, so, ipa, apk, lnk, 압축 파일은 보안 이슈로 업로드 제한됩니다.

### 생성 완료 <a href="#id-4" id="id-4"></a>

* 검토 후 **[생성 하기]** 버튼을 누르면 하단과 같은 링크 생성 전 확인 사항 안내창이 생성됩니다.

![[img-1f5bf9780179.png]]

*전송 전 확인 사항 안내*

![[img-e2d4be18d983.png]]

*생성된 계약 링크와 QR 코드*

* 확인 사항을 읽고 **[모두 동의 후 링크 생성]** 버튼을 누르면 계약 링크와 QR코드가 생성 됩니다.
* 생성된 링크/QR은 복사 및 다운로드가 가능하며, 해당 링크/QR을 통해 접속한 서명자(상대방)는 회원 가입 없이 바로 서명을 진행할 수 있습니다.

## 계약 입장 <a href="#id-1" id="id-1"></a>

* 생성된 링크 또는 QR을 통해 아래와 같은 입장 화면으로 연결 됩니다. 서명자는 이메일 또는 휴대폰 번호 중 하나를 입장 수단으로 선택할 수 있습니다.

> [!info]
> 링크 계약 생성 시 휴대폰 인증을 선택한 경우 휴대폰 번호로만 계약 입장 가능합니다.

![[img-3093ee22ce9a.png]]

1. **이메일:** 이름과 이메일을 입력 후 계약에 입장합니다. 입장하여 생성된 계약은 입력한 이메일로 발송 됩니다.
2. **휴대폰 번호:** 이름과 휴대폰 번호를 입력 후 계약에 입장합니다. 입장하여 생성된 계약은 입력한 번호의 카카오톡으로 발송됩니다. 만일 카카오톡에 가입되어있지 않은 번호일 경우 SMS로 발송됩니다.

* 필요 정보 입력 후 **[계약 입장]** 버튼을 클릭하면 아래와 같이 계약 현황 화면으로 이동합니다. 계약 현황 화면에서 **[이동하기]** 버튼을 클릭해 계약서를 열람할 수 있습니다.

![[img-e78da8439c48.png]]

### 입력 시작

* 계약서를 확인 후 계속 진행을 원하시면 좌측 **[입력 시작]** 버튼을 클릭합니다.

![[img-8dc9e5a78572.png]]

> [!note] 계약 거절 방법
> 계약서에 이상이 있거나, 더 이상 계약을 진행하고 싶지 않은 경우, 계약을 취소할 수 있습니다. \
> 계약 거절 방법에 대해 더 자세히 알고 싶은 경우 아래 링크를 확인하시기 바랍니다.
>
> > [!tip] 관련 문서
> > [[계약서 열람 및 서명/수신자 서명 방법/계약 서명 전 거절 방법|계약 서명 전 거절 방법]]

### 입력 완료

* 필수 내용 및 서명/도장을 입력을 완료하신 경우 마지막 입력 칸의 완료 버튼 또는 좌측에 입력 완료 버튼을 클릭합니다

![[img-7048d2ebc44d.png]]

* 입력 완료 버튼 클릭 시 **입력 완료 전 최종 확인 사항** 안내가 생성됩니다. 해당 안내를 꼼꼼히 확인 후 동의 및 **[확인]** 버튼을 클릭해주세요.

![[img-d8585b865e5c.png]]

> [!danger]
> **확인 버튼 클릭 후에는 수정 및 추가 입력이 불가능 합니다.**

## 링크 계약 관리

* 왼쪽 메뉴 탭에서 계약 관리 하단에 있는 **[링크 계약]** 을 클릭합니다.

![[img-48879f0aa4d8.png]]

### 링크  계약 관리 <a href="#undefined-1" id="undefined-1"></a>

* 링크 계약 관리를 클릭하면 하단 이미지와 같이 목록을 확인할 수 있습니다.
* 검색 기능을 통해 계약명, 서명자 및 생성자 이름을 검색할 수 있습니다.

![[img-b816723e895b.png]]

* **엑셀 내려받기** - 파기를 원하는 링크 계약을 선택한 후 계약 파기를 누르면 해당 링크 계약에 포함된 체결 되지 않은 모든 계약을 일괄 파기할 수 있습니다.
* **다운로드** - 다운로드를 원하는 계약의 우측 다운로드 버튼을 누르면 해당 계약 내 체결된 계약서를 일괄 다운로드 할 수 있습니다.
* **일괄 다운로드** - 다운로드 받을 링크 계약 이름 앞 부분에 위치한 체크 박스를 선택한 후 다운로드를 클릭하면 해당 링크 계약 내 체결된 계 약서를 일괄 다운로드 할 수 있습니다.
* **설명** - 해당 링크 계약에 대한 설명을 100자 이내로 입력할 수 있습니다.

![[img-baf59af1e1f8.png]]

### 링크 계약 세부 확인 <a href="#undefined-2" id="undefined-2"></a>

* 링크 계약에 입장하면 해당 계약에 관한 정보를 아래와 같이 확인할 수 있습니다.

![[img-d7a8dbfd0ca8.png]]

* **확인 가능한 정보:**
  * **계약 현황**: 체결, 내 입력 대기, 상대방 입력 대기, 계약 파기 및 거절 현황이 표시 됩니다.
  * **정보**: 생성된 계약 정보, 링크/QR코드 및 해당 계약 설정을 확인할 수 있습니다.
  * **계약명**: [계약명\_서명자 이름] 형식으로 계약명이 표시됩니다.
  * **서명자**: 서명을 하는 모든 서명자의 이름이 표시됩니다.
  * **이메일 / 휴대폰 번호:** 서명자가 링크/QR을 통해 입장 시 입장 방법으로 선택한 수단 정보가 표시됩니다. [휴대폰 인증 설정 시 이메일로 입장 불가]
  * **상태:** 계약의 상태를 확인할 수 있습니다 [상대방 입력 대기, 내 입력 대기, 거절, 파기 및 체결]
  * **생성 일자:** 서명자가 링크/QR을 통해 입장하여 생성한 일자를 표시합니다.
  * **체결 일자**: 모든 서명자가 서명을 완료하여 체결된 일자를 표시합니다.

### 링크 계약 활성화 / 비활성화 / 삭제

* 생성된 링크 계약의 상태를 언제든지 손쉽게 변경할 수 있습니다.

![[img-3d5d4253b84d.png]]

* **활성화**: 링크가 활성화 되어있는 상태이며, 상대방이 링크에 입장하여 계약 생성 및 서명할 수 있습니다.
* **비활성화**: 링크가 비활성화 되어있는 상태이며, 상대방이 링크에 입장할 수 없습니다.
* **링크 삭제**: 해당 링크를 통해 생성된 계약이 없을 때 삭제할 수 있습니다.

### 계약 링크/QR코드 재확인

* 만일 링크 또는 QR코드 재 확인이 필요할 시 계약 현황 우측에 위치한 **[계약 링크/QR 코드]** 버튼을 클릭하여 해당 계약의 링크와 QR코드를 확인 및 저장 할 수 있습니다.

![[img-f92a4594516a.png]]

### 링크 계약 설정

* 링크 계약 설정 변경을 원할 경우, 계약 현황 우측에 있는 **[링크 계약 설정]** 버튼을 클릭하여 변경할 수 있습니다.

![[img-593195df12c2.png]]

1. 계약 체결 수 제한: 체결 가능한 최대 계약 건수를 변경할 수 있습니다.
2. 기한 설정: 기한 변동 발생 시 원하는 기한으로 변경할 수 있습니다.
3. 입장 화면 문구: 계약 입장 시 서명자에게 보여줄 문구를 변경할 수 있습니다.

> [!danger]
> 링크 계약 주의 사항
>
> * 모든 계약이 체결된 후 링크를 비활성화 하지 않으면 언제든지 링크/QR 소유자가 입장하여 계약을 생성할 수 있습니다. 계약 생성 시 계약 건수가 차감 되니, 불필요한 차감을 원하지 않을 경우 계약 종료 후 링크를 비활성화 해주세요.
