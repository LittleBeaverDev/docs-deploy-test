# 가이드 메뉴 순서 관리 (`sortspec.md`)

이 파일 하나가 **Obsidian 파일 탐색기**와 **웹 가이드 사이드바·이전/다음 페이지·`llms.txt`**의 순서를 함께 제어합니다.

## 사용 방법
1. 위쪽 `sorting-spec`에서 순서를 바꾸고 싶은 폴더 또는 문서 이름의 **줄 위치만 옮겨 저장**하면 됩니다.
2. 새 카테고리나 문서를 추가한 뒤 원하는 위치에 이름을 한 줄 넣으면 코드 수정 없이 웹 사이드바에도 자동 반영됩니다.
3. 문서를 임시 비공개하려면 해당 문서 상단 속성에 `publish: false`를 추가하세요.

> 이 파일 자체는 `publish: false` 설정으로 웹 사이트에는 노출되지 않습니다.
