도뉴에서 발송하는 계약 관련 이메일/카카오톡 양식을 본인 회사에서 보내는 것처럼 변경하는 기능을 알아보겠습니다.

> [!warning]
> 이메일 양식은 통합 되어 있지 않아, 대표 계정 및 팀 계정 모두 각각 변경해야 합니다.
>
> 변경하지 않은 계정은 기존 DONUE의 기본 양식으로 발송됩니다.
>
> * 만일 팀원 계정에서 이메일 양식 변경 화면이 보이지 않을 경우 직책 관리에서 브랜딩 관리 권한을 부여해야 합니다.

## 이메일 양식

1. 왼쪽 메뉴에서 [설정] 버튼을 클릭하여 화면을 이동한 후, [이메일/카카오톡 양식] 탭을 클릭합니다.
2. 이동한 탭으로 이동하면 현재 도뉴에서 발송하는 이메일 양식과 정보들을 볼 수 있습니다. 여기서 [수정] 버튼을 클릭합니다.

![[img-d358edafeeff.png]]

3. [수정] 버튼을 클릭하면 보내는 사람, 로고 이미지, 로고 링크, 버튼 색상, 버튼 텍스트 색상을 변경할 수 있으며, 왼쪽 이미지를 통해 실시간으로 변경되는 이메일 양식을 확인할 수 있습니다.

![[img-b5bd24de241e.png]]

4. 변경 후 [완료] 버튼을 클릭하면, 이후 도뉴에서 발송하는 계약 관련 메일은 변경한 이메일 양식으로 전송됩니다.

## 카카오톡 양식

> [!success]
> 대표 관리자 계정에 카카오톡 채널 연동 시 하위 팀원 계정에 자동 적용됩니다.

도뉴에서 발송하는 카카오톡 양식을 변경하기 위해서는 본인이 운영하고 있는 카카오톡 채널이 필요합니다. 운영 중인 카카오톡 채널이 있으면 2번으로 넘어가 주세요.

### **1. 카카오톡 채널 생성**

다음 링크를 들어가 카카오 비즈니스에 가입합니다. 가입 후 카카오 비즈니스 통합 회원으로 전환해주세요.

링크 : <https://business.kakao.com/>​

계정 생성 후 화면에 입장하면 채널을 생성할 수 있습니다. [+새 채널만들기] 버튼을 클릭하여 운영할 채널을 만들어주세요.

![[img-067d5b9fcc5a.png]]

### **2. 채널 공개 설정**

연동할 채널을 선택하여 상세 화면으로 입장합니다. 화면 오른쪽 하단에서 [프로필 설정 버튼] > 채널 공개를 ON으로 설정합니다.

( 채널을 비공개로 설정하면, 채널 연동이 불가합니다.)

![[img-9e51fa5f09e7.png]]

### **3. 카카오톡 채팅 설정**

왼쪽 메뉴에서 [1:1 채팅] > [채팅 설정] 버튼을 클릭합니다.

이동한 화면에서 1:1 채팅 사용을 ON으로 설정 후 [저장] 버튼을 클릭합니다.

![[img-8f01b7186fbf.png]]

### **4. 도뉴와 카카오톡 채널 연동**

왼쪽 메뉴에서 [설정] 버튼을 클릭하여 화면을 이동한 후, [이메일/카카오톡 양식] 탭을 클릭합니다.

화면 하단으로 이동하면 카카오톡 양식이 제공되며, [연동] 버튼을 클릭합니다.

![[img-96f42d3f7ad1.png]]

버튼을 클릭하면 카카오톡 채널 연동 팝업창이 제공됩니다. 연동에 필요한 정보들은 다음과 같습니다.

![[img-90b969649569.png]]

1. 채널 검색용 ID : 채널 생성시 등록한 검색용 ID를 입력합니다. ID가 기억나지 않으실 경우 카카오톡 비즈니스 화면 왼쪽 메뉴에서 [관리] > [상세설정]에서 확인할 수 있습니다.
2. 관리자 휴대폰 번호 : 채널을 생성한 관리자의 휴대폰 번호를 입력 후 [인증 요청] 버튼을 눌러 인증 번호를 받습니다.
3. 사업자 카테고리 : 제공하는 서비스 성격에 맞는 카테고리를 선택합니다.

모든 정보 입력 후 [연동] 버튼을 클릭하면 연동이 완료됩니다.

연동에는 카카오의 검수가 진행되며, 최대 3일이 소요됩니다. 검수 기간 동안에는 도뉴에서 보내는 알림톡이 전송됩니다.

> [!danger]
> **카카오톡 채널 연동 중 [유효하지 않은 인증번호입니다.]가 나오는 경우는 아래와 같습니다.**
>
> * 해당 채널이 비즈니스 채널로 전환이 되어있지 않은 경우.
> * 채널 검색용 ID를 잘못 입력한 경우.
> * 관리자 휴대폰 번호를 잘못 입력한 경우.
> * 인증번호를 잘못 입력한 경우.
> * 해당 채널 고객센터 번호가 입력되지 않은 경우 [관리자 센터 → 프로필 → 채널홈 설정 → 기본정보 → 고객센터 입력 → 고객센터 연락처 정보 입력]
