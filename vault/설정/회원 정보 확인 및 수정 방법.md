회원 정보 확인과 수정, 비밀번호 변경 및 회원 탈퇴 하는 방법에 대해서 알아보겠습니다.

## **회원 정보 확인 및 수정**

1. 왼쪽 메뉴에서 **[설정]** 버튼을 클릭하여 화면을 이동합니다.

![[img-10718d593c43.png]]

2. 이동한 화면에서 아래와 같은 정보를 확인할 수 있으며 우측 **[수정]** 버튼을 클릭하면 정보 변경이 가능 합니다.

![[img-20235b5ef674.png]]

*<strong>기업 정보 확인 및 수정은 기업 회원만 가능합니다.</strong>*

3. 수정 완료 후에는 **[완료]** 버튼을 클릭합니다.

![[img-1ba7f1fb6800.png]]

> [!danger]
> 이메일 주소 및 사업자 등록번호는 **수정 불가**합니다.
>
> 사업자 등록번호 변경이 필요한 경우 [채널톡](https://donue.channel.io/lounge)을 통해 고객센터로 문의해 주세요.

## 비밀번호 변경

1. 회원 정보 하단으로 내려가면 비밀번호 변경 우측 **[변경]** 버튼을 클릭합니다.

![[img-17875f0ed98c.png]]

2. 새로운 비밀번호 및 비밀번호 확인을 입력 후 **[완료]** 버튼을 클릭합니다.

![[img-5d3ea2008a5e.png]]

> [!info]
> 비밀번호는 영문/숫자/특수 문자 조합 8자 이상 입력해야 합니다.

## 회원 탈퇴

> [!warning]
> 기업 회원은 직접 탈퇴가 불가능 하며, 아래의 방법은 개인 회원에게만 적용 됩니다.
>
> 기업 회원은 [채널톡](https://donue.channel.io/lounge)을 통해 고객센터로 문의 주시면 탈퇴 진행을 도와 드리겠습니다.

### 개인 회원 탈퇴 방법

1. 회원 정보 하단 회원 탈퇴 우측에 있는 **[탈퇴]** 버튼을 클릭합니다.

![[img-4c9ba97d8f50.png]]

2. 회원 탈퇴 안내 내용을 확인 후 **[인증번호 전송]** 버튼을 클릭합니다.

![[img-7ba6000a37b7.png]]

3. 이메일로 발송 된 인증번호 입력 및 **[확인]** 버튼을 클릭 후 하단 동의 사항에 체크하면 **[탈퇴 요청]** 버튼이 활성화 됩니다.

![[img-370ce96b2dd7.png]]

4. **[탈퇴 요청]** 버튼을 클릭하면 아래와 같은 확인 메세지가 생성됩니다. **[확인]** 버튼 클릭 시 탈퇴가 완료 됩니다.

![[img-797cfff561b7.png]]

> [!danger]
> **탈퇴 요청 전 확인 사항 (기업/개인 공통)**
>
> 1. 현재 사용 중인 요금제가 있을 경우, **[[요금제/요금제 구매|요금제 해지]]** 를 먼저 진행해주세요.
> 2. **진행 중인 계약** 이 있다면 계약 **파기 또는 체결**되어야 합니다.
> 3. 회원 탈퇴가 완료되는 순간 **모든 계정 정보 및 계약 파일은 삭제되며 복구 불가**합니다. 중요한 계약서는 외부로 다운로드 받으신 후 탈퇴 요청해 주시길 바랍니다.
